Small habits, big difference

You do not need special tools to be much safer online. These five habits block most everyday attacks.

Your security checklist

  • ✓

    Use a password manager

    Make every password long and unique so one leak cannot open other accounts.

  • ✓

    Turn on two-factor authentication

    A code or app prompt stops attackers who only have your password.

  • ✓

    Install updates

    Updates patch the vulnerabilities attackers rely on.

  • ✓

    Think before you click

    Check the sender and the link address before you open anything unexpected.

  • ✓

    Back up your files

    A recent backup makes ransomware far less scary.
